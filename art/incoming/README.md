# Drop new art here

Upload new models (`.glb`) and their reference images (`.png`) to this
folder on GitHub: open it, then **Add file > Upload files**, drag the files
in and **Commit changes**. Name each pair after the object, e.g. `kite.glb`
and `kite.png`.

Each one is then optimized into `public/models/`, the originals move to
`art/source/`, and `art/SOURCES.md` records how they were made. Only
generate on plans that grant ownership (see `art/SOURCES.md`).
