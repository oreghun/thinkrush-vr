# Art sources

Every model or image in the game that is not built in code is listed here,
with how it was made and why we may use it. The competition rules allow only
code-generated assets, CC0 assets, and assets the owner generated on a plan
that gives them ownership (see CLAUDE.md). No CC-BY or other
attribution-required assets: Meshy's free plan is CC BY 4.0, so it is never
used for game assets.

How an asset gets in:

1. The owner uploads the original files to `art/incoming/`.
2. `scripts/optimize-model.mjs` makes the game copy in `public/models/`
   (JPEG colour maps at most 1024 px for set pieces, 512 px for the small
   table objects; geometry unchanged).
3. The originals move to `art/source/` and get a row below.

`art/` is not part of the build; only `public/models/` ships.
